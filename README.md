# esp32-vortex-iot
VORTEX is an integrated IoT and robotics platform featuring offline VC-02 voice control, ESP32 master logic, and 4WD locomotion via L298N drivers. It coordinates the ESP8266 node for 4-channel appliance switching and DHT22 telemetry over Blynk, paired with an Arduino Uno OLED display for emotive facial animations and synced DFPlayer audio feedback.
